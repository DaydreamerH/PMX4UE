## 能力与边界

- Capability tier（择一）：`basic` 基础清单/机械任务 / `specialist` 边界明确的专项 / `advanced` 疑难语义与跨系统诊断。选择标准见 `docs/agent-collaboration.md`。
- 必需工具与视觉能力（如需看图，列出原图/原尺寸要求）：
- 宿主实际执行者 / 工具、上下文与能力匹配依据：
- 成本信息：已知价格及来源 / `price_unknown`；选择理由和预期重试成本（不编造价格）：
- 预算（时间、轮次或 token）：
- 升级条件（何时停止并交回主智能体）：
- 允许写入的文件完整清单：
- UE 资产命名空间（如适用）：
- 执行权限：默认只读分析，仅写自己的报告；获派发写权限时只改上述清单。UE 执行仅限主智能体明确排队给唯一工程执行者的操作：

## 交付与完成标准

- 具体产物及保存位置：
- 完成标准（可核验）：
- 原始证据（输入/输出指纹、命令或工具记录、原始报告、原尺寸图路径等）：
- 独立审阅（如任务需要）：审阅者直接检查真实层级、图连接或原尺寸图等原始对象；不能只依作者总结。注明检查对象与发现：
- 审阅任务首先给需求和原始证据；作者假设/总结若必须提供，单列为待核实内容：
- 限制：缺少动画不阻止材质或静止性能工作；动态结论标为待验证。

## 子智能体回报

- Task ID：
- 任务进度：`pending` / `running` / `done` / `failed`（done 只指本任务范围）：
- 验收记录：`implemented` / `measured` / `agent_reviewed` / `user_approved`（逐项记录证据或 pending/failed，不互相推导）：
- 产物与实际改动文件：
- 审阅的准确资产组合及保存后重载来源（非“最新版本”）：
- 实际打开的原图/目标区域清单、看图者；他人补录指纹时另列元数据编写者：
- 完成标准逐项结果：
- 原始证据及指纹：
- 审阅对象、方法与发现（未审阅写 `pending`）：
- 未完成、失败原因及不确定性：
- 后续依赖 / 建议升级条件：
- 主智能体采用/退回及理由 / 输入变化后哪些结果失效：

无可用委派工具时，由单智能体完成并按实际情况标记；不得假称子智能体执行或审阅。
